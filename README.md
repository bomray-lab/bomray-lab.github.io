# Bomray Lab Website

Official static website for Bomray Lab Atlassian apps.

## Local preview

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages

For the repository `bomray-lab.github.io`, GitHub Pages can publish directly from the `main` branch root.

Go to:

`Settings → Pages → Build and deployment → Deploy from a branch → main / root`
